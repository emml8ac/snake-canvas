# Snake — Canvas Edition

Classic Snake game built with pure HTML, CSS, and JavaScript. Rendered on HTML5 Canvas.

## Controls

- **Arrow Keys**: Move snake
- **Space**: Toggle pause / Restart after game over
- **Swipe (mobile)**: Change direction (tap to pause/restart)

## Features

- Progressive speed scaling — gets faster every 50 points
- High score persistence via `localStorage`
- Responsive design — works on desktop and mobile
- Touch swipe controls for mobile play
- Pause on tab blur, resume on refocus

## Tech Stack

Vanilla HTML5, CSS3, JavaScript (ES6+). Zero dependencies. No build step.

## Play

Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
